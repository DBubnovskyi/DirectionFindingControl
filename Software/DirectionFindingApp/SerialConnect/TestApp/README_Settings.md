# Система збереження налаштувань

## Огляд

Додаток автоматично зберігає та завантажує налаштування користувача у файл `Settings.json`.

## Розташування файлу налаштувань

Файл зберігається за шляхом:
```
C:\Users\{ІмяКористувача}\AppData\Roaming\DirectionFindingApp\Settings.json
```

## Що зберігається

### 1. Налаштування карти (Map)
- **Latitude** - широта центру карти
- **Longitude** - довгота центру карти
- **Zoom** - рівень зуму карти
- **MapProvider** - провайдер карти (наразі OpenStreetMap)

### 2. Налаштування станції (Station)
- **Latitude** - широта станції пеленгації
- **Longitude** - довгота станції пеленгації
- **IsSet** - чи встановлені координати станції

### 3. Налаштування COM-порту (Serial)
- **LastPort** - останній використаний COM-порт
- **UseSimulator** - використовувати симулятор замість реального порту

### 4. Налаштування сканування (Scan)
- **StartAzimuth** - початковий азимут для сканування
- **EndAzimuth** - кінцевий азимут для сканування
- **Step** - крок сканування
- **PendulumMode** - режим маятника (прямо-назад)
- **ForbiddenZoneStart** - початок сліпої зони (азимут, за замовчуванням 175°)
- **ForbiddenZoneEnd** - кінець сліпої зони (азимут, за замовчуванням 185°)

**Сліпа зона (Forbidden Zone):**
- Сектор куди заборонено крутити антену
- При спробі встановити азимут у сліпій зоні, він автоматично коригується до найближчої межі
- Наприклад: якщо сліпа зона 175-185°, і ви задаєте 178°, антена піде на 175°, а якщо 181° - на 185°
- Візуалізується на карті червоним напівпрозорим полігоном
- Полігон малюється точками через кожен градус від центру станції на відстань 50 км

## Автоматичне збереження

Налаштування автоматично зберігаються в наступних випадках:

1. **При зміні позиції карти** - коли ви переміщуєте карту
2. **При зміні зуму** - коли ви змінюєте масштаб карти
3. **При встановленні координат станції** - коли натискаєте кнопку "Set Coords"
4. **При переміщенні маркера станції** - коли перетягуєте червоний маркер
5. **При зміні забороненої зони** - коли змінюєте значення numFobStart або numFobEnd
6. **При закритті програми** - фінальне збереження всіх налаштувань

## Автоматичне завантаження

При запуску програми автоматично:

1. Завантажується положення карти (центр і зум)
2. Завантажуються координати станції (якщо вони були збережені)
3. Відновлюється маркер станції на карті
4. Завантажуються значення сліпої зони (numFobStart і numFobEnd)
5. Малюється полігон сліпої зони на карті

## Приклад файлу Settings.json

```json
{
  "Map": {
    "Latitude": 50.4501,
    "Longitude": 30.5234,
    "Zoom": 12,
    "MapProvider": "OpenStreetMap"
  },
  "Station": {
    "Latitude": 50.4501,
    "Longitude": 30.5234,
    "IsSet": true
  },
  "Serial": {
    "LastPort": "COM3",
    "UseSimulator": false
  },
  "Scan": {
    "StartAzimuth": 0,
    "EndAzimuth": 360,
    "Step": 10,
    "PendulumMode": true,
    "ForbiddenZoneStart": 175,
    "ForbiddenZoneEnd": 185
  }
}
```

## Програмне використання

### Читання налаштувань
```csharp
var settings = SettingsManager.Current;
double latitude = settings.Map.Latitude;
double zoom = settings.Map.Zoom;
```

### Оновлення налаштувань
```csharp
SettingsManager.Update(s =>
{
    s.Map.Latitude = 50.4501;
    s.Map.Longitude = 30.5234;
    s.Map.Zoom = 12;
});
```

### Скидання до значень за замовчуванням
```csharp
SettingsManager.Reset();
```

### Отримання шляху до файлу
```csharp
string path = SettingsManager.GetSettingsPath();
Console.WriteLine($"Settings file: {path}");
```

## Класи

### AppSettings
Головний клас, що містить всі налаштування програми.

### SettingsManager
Статичний клас, що відповідає за:
- Автоматичне завантаження налаштувань при першому зверненні
- Збереження налаштувань у JSON формат
- Thread-safe доступ до налаштувань
- Створення файлу налаштувань якщо його не існує

## Важливо

- Налаштування зберігаються автоматично, не потрібно нічого робити вручну
- При першому запуску створюється файл з налаштуваннями за замовчуванням
- Файл можна редагувати вручну (програма має бути закрита)
- При помилці читання файлу створюються налаштування за замовчуванням
