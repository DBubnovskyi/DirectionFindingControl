# Приклади використання симулятора

## Базовий тест обертання

1. Підключіться до Serial Monitor (115200 baud)
2. Виконайте команди:

```
EN,1        # Дозволити рух
AN,0        # Встановити початкову позицію 0°
AN,90       # Повернути на 90°
#AN         # Перевірити поточну позицію
AN,180      # Повернути на 180°
AN,270      # Повернути на 270°
AN,0        # Повернути назад на 0°
```

## Тест швидкості

Максимальна швидкість: 5°/секунду

```
EN,1
MAXS,255    # Максимальна швидкість
AN,0
AN,180      # Має зайняти приблизно 36 секунд (180° ÷ 5°/с)
```

## Тест точності

Точність: ±1°

```
EN,1
TOL,0.4     # Встановити допуск 0.4°
AN,45       # Встановити ціль 45°
#AN         # Перевірити результат (має бути 45 ± 1°)
```

## Тест азимуту

```
EN,1
AZ,0,90     # Встановити зміщення азимуту на 90°
AZ,45       # Встановити азимут 45°
#AZ         # Перевірити поточний азимут
#AN         # Перевірити відповідний кут
```

## Моніторинг руху

Використовуйте OLED дисплей для спостереження:
- Current: поточний кут датчика
- Target: цільовий кут
- Status: ROTATING/STOPPED
- Speed: поточна швидкість мотора (0-255)
- Dir: напрямок (CW=за годинниковою, CCW=проти, ---=стоп)

## Тест заборони руху

```
EN,1
AN,90       # Почати обертання
EN,0        # Заборонити рух (мотор зупиниться негайно)
#ST         # Перевірити статус
```

## Перевірка статусу

```
#ST         # Повний статус: ST,<поточний_кут>,<статус_обертання>,<швидкість>,<помилка_датчика>,<помилка_мотора>
#ERROR      # Помилки: ERROR,<код_помилки_датчика>,<код_помилки_мотора>
```

## Налаштування параметрів

```
# Встановити допуск позиціонування
TOL,1.0     # 1 градус

# Встановити діапазон швидкості
MINS,140    # Мінімальна швидкість
MAXS,255    # Максимальна швидкість

# Встановити кут гальмування
BA,15       # Почати гальмування за 15° до цілі

# Перевірити параметри
#TOL
#MINS
#MAXS
#BA
```

## Ініціалізація системи

```
# Перевірити стадію ініціалізації
#IN         # IN,<стадія> (0-4)

# Якщо потрібно, виконати ініціалізацію
IN,1        # Перехід до стадії 1
IN,2        # Перехід до стадії 2
IN,3        # Перехід до стадії 3
IN,4        # Завершити ініціалізацію
```

## Очікувані результати

### При команді AN,90 (з позиції 0°):
- Мотор починає обертання
- Швидкість плавно збільшується
- При наближенні до 90° швидкість зменшується
- Мотор зупиняється при 90° ± 1°
- Час руху: приблизно 18 секунд (90° ÷ 5°/с)

### На OLED дисплеї ви побачите:
```
MOTOR SIMULATOR
───────────────────
Current: 45.3°
Target:  90.0°
Status:  ROTATING
Speed:   180
Dir: CW  [████████]
```

### При зупинці:
```
MOTOR SIMULATOR
───────────────────
Current: 90.1°
Target:  90.0°
Status:  STOPPED
Speed:   0
Dir: ---
```

## Troubleshooting

### Мотор не обертається
1. Перевірте: `#EN` (має бути EN,1)
2. Якщо EN,0, виконайте: `EN,1`
3. Перевірте помилки: `#ERROR`

### Симуляція дуже повільна
- Це нормально! Максимальна швидкість 5°/с
- Повний оберт (360°) займає 72 секунди

### Неточне позиціонування
- Це нормально! Точність ±1°
- Ви можете налаштувати допуск: `TOL,<значення>`

### OLED не оновлюється
- Перевірте підключення I2C
- Перевірте адресу OLED (0x3C або 0x3D)
- Перезавантажте ESP8266
