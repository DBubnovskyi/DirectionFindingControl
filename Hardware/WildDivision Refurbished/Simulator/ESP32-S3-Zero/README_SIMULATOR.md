# Симулятор контролера мотора для ESP8266 12F

## Опис

Цей проект є симулятором системи керування мотором для ESP8266 12F з OLED екраном. 
Він імітує роботу реального контролера мотора з датчиком кута, але без підключення 
реальної периферії.

## Характеристики симуляції

### Мотор
- **Максимальна швидкість обертання**: 5°/секунду
- **Плавне прискорення/гальмування**: Так
- **Діапазон швидкості**: 0-255 (PWM)

### Датчик кута (MT6701 Simulator)
- **Точність позиціонування**: ±1 градус
- **Діапазон вимірювання**: 0-360°
- **Імітація помилок**: Випадкова помилка ±1° для реалістичності

### OLED дисплей (128x64)
- **Інтерфейс**: I2C (SDA=GPIO4/D2, SCL=GPIO5/D1)
- **Адреса**: 0x3C
- **Відображає**:
  - Поточний кут
  - Цільовий кут
  - Статус обертання
  - Швидкість мотора
  - Напрямок обертання

## Підключення

### ESP8266 12F
- **GPIO4 (D2)**: I2C SDA для OLED
- **GPIO5 (D1)**: I2C SCL для OLED
- **GPIO2**: Вбудований LED (індикатор)
- **USB**: Серійний порт для команд (115200 baud)

### OLED Екран
- VCC → 3.3V
- GND → GND
- SDA → GPIO4 (D2)
- SCL → GPIO5 (D1)

## Використання

### Серійні команди

Підключіться до Serial Monitor (115200 baud) та використовуйте команди:

#### GET команди (читання стану)
- `#AN` - Отримати поточний кут
- `#AZ` - Отримати азимут
- `#ST` - Отримати повний статус
- `#SP` - Отримати швидкість мотора
- `#EN` - Перевірити чи дозволено рух
- `#AC` - Перевірити активність системи

#### SET команди (керування)
- `AN,<кут>` - Встановити цільовий кут (0-360°)
- `AZ,<азимут>` - Встановити цільовий азимут
- `EN,1` - Дозволити рух
- `EN,0` - Заборонити рух
- `TOL,<значення>` - Встановити допуск (0.1-5.0°)
- `MINS,<значення>` - Встановити мінімальну швидкість (0-255)
- `MAXS,<значення>` - Встановити максимальну швидкість (0-255)

### Приклади

```
# Дозволити рух
EN,1

# Повернути на 90 градусів
AN,90

# Перевірити поточний кут
#AN

# Встановити допуск 0.5 градусів
TOL,0.5

# Отримати статус
#ST
```

## Робота симулятора

1. **Датчик кута** відстежує швидкість мотора та обчислює поточний кут
2. **Мотор** має максимальну швидкість 5°/с (при PWM=255)
3. **Випадкова помилка** ±1° додається до вимірювань для реалістичності
4. **OLED дисплей** оновлюється кожні 100мс
5. **Всі команди** працюють так само як на реальному пристрої

## Компіляція та завантаження

```bash
# З використанням PlatformIO
pio run -t upload

# Або через VS Code PlatformIO extension
# Натисніть "Upload" в панелі PlatformIO
```

## Налаштування OLED

Якщо ваш OLED використовує іншу адресу (0x3D замість 0x3C), 
змініть `SCREEN_ADDRESS` в файлі `lib/OLEDDisplay/OLEDDisplay.h`:

```cpp
#define SCREEN_ADDRESS 0x3D
```

## Діагностика

### OLED не відображається
- Перевірте підключення SDA/SCL
- Спробуйте іншу адресу (0x3C або 0x3D)
- Перевірте живлення 3.3V

### Команди не працюють
- Переконайтеся що швидкість Serial Monitor = 115200
- Перевірте що команди надсилаються з переведенням рядка (NL)

### Симуляція працює некоректно
- Перезавантажте ESP8266
- Перевірте що рух дозволено командою `EN,1`

## Технічні деталі

### Алгоритм симуляції мотора

Швидкість обертання розраховується як:
```
degreesPerSecond = (motorSpeed / 255.0) × 5.0
deltaAngle = degreesPerSecond × (elapsed / 1000.0)
```

### Алгоритм додавання помилки датчика

```cpp
float error = (random(-100, 100) / 100.0); // ±1°
angle = simulatedAngle + error;
```
